\doxysubsection{Detailed Description}
Implementation file for converting a propositional logic expression tree into Conjunctive Normal Form (CNF). 

This file contains the functions that perform the multi-\/step process of CNF conversion\+:
\begin{DoxyEnumerate}
\item IMPL\+\_\+\+FREE\+: Eliminate all implication operators.
\item NNF\+: Convert the expression into Negation Normal Form by moving negations inward.
\item CNF (with DISTR)\+: Distribute ORs over ANDs to create a conjunction of disjunctions. The final {\ttfamily to\+CNF} function orchestrates this entire pipeline. 
\end{DoxyEnumerate}

Step 2 of CNF conversion\+: Converts an implication-\/free tree to Negation Normal Form (NNF). 

In NNF, negations (\textquotesingle{}\texorpdfstring{$\sim$}{\string~}\textquotesingle{}) only appear directly in front of atomic propositions (variables), forming literals. This is achieved by applying De Morgan\textquotesingle{}s laws and eliminating double negations. The input tree must already be implication-\/free.
