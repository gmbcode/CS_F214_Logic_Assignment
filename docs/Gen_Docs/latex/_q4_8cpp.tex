\doxysubsection{Detailed Description}
Implementation file for calculating the height of an expression parse tree. 

This file contains the logic to determine the height of a given parse tree, which is defined as the number of nodes along the longest path from the root node down to the farthest leaf node.

int get\+Parse\+Tree\+Height (\begin{DoxyParamCaption}\item[{\mbox{\hyperlink{struct_tree_node}{Tree\+Node}} \texorpdfstring{$\ast$}{*}}]{root}{}\end{DoxyParamCaption})}



Recursively calculates the height of a parse tree. 

The height of a tree is the length of the longest path from the root to a leaf. An empty tree (nullptr) has a height of 0. A tree with a single node has a height of 1. The function works by finding the height of the left and right subtrees and returning 1 (for the current node) plus the height of the taller subtree.
