\doxysubsection{Detailed Description}
Implementation file for evaluating and generating truth tables for expression parse trees. 

This file contains functions to recursively evaluate the boolean value of a parse tree given a specific assignment of truth values to its variables. It also includes functionality to generate and print a complete truth table for the expression.

Evaluates the truth value of an expression tree for a single assignment of truth values. 

This function recursively traverses the tree. For operator nodes, it computes the result based on the values of its children. For variable (leaf) nodes, it looks up the value in the provided map.

Generates and prints a complete truth table for the given expression tree. 

This function first prints a header with all the variable names. It then iterates through all possible combinations of truth values (2\texorpdfstring{$^\wedge$}{\string^}n rows, where n is the number of variables). For each combination, it evaluates the expression and prints the result.
